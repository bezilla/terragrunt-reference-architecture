# 1. OpenTofu as the default binary, Terraform as a drop-in

Status: Accepted

## Context
HashiCorp relicensed Terraform under the BSL in August 2023. OpenTofu is the MPL-licensed fork
governed by the Linux Foundation, CLI-compatible with the Terraform workflow this repo uses. A
reference repo should not force a licensing decision on the reader, but it should have a default.

## Decision
Default every invocation to OpenTofu via `terraform_binary = "tofu"` in `live/root.hcl`, and pin
`opentofu` in `mise.toml`. Module `required_version` constraints (`~> 1.8`) are satisfied by both
OpenTofu 1.8+ and Terraform 1.8+, so a reader who must use Terraform only changes the binary.

## Consequences
- No BSL-licensed code is required to use this repo.
- Provider lockfiles are generated by `tofu providers lock`; the registry namespace in
  `.terraform.lock.hcl` is `registry.opentofu.org`. A Terraform user re-locks against
  `registry.terraform.io`.
- Native testing uses `tofu test` / `*.tftest.hcl`, which Terraform also supports.
